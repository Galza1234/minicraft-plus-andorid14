# minicraft-plus-andorid14
## Installation on Android

1. Download the latest `.apk` file from the **Releases** section of this repository.
2. If you downloaded it on a PC, transfer the APK to your Android phone with a USB cable, cloud storage, or another trusted method.
3. Open the APK on your phone using the Files app.
4. Android may ask for permission to install apps from that source. Enable **Allow from this source** for the browser or file manager you used.
5. Tap **Install**.

Google Play Protect may sometimes show a warning because this app is not published on Google Play. Only choose **Install anyway** after confirming that the APK was downloaded from this repository’s official Release.

## Development Status

This project is still in development and may occasionally be unstable, but it is already playable. Community feedback, bug reports, and contributions are welcome.

## Current Mobile Changes

- Touch controls for movement, inventory, attacks, and crafting
- Faster tree and normal stone mining
- Tools currently do not lose durability
- Support focused on Android 14, with future Android versions planned
